# MindCommons project goal

## The mission

Build an open-source demonstration of how software might check a community's AI research rules and each person's separate permission before using their contributions.

This is a technical prototype for a possible Mozilla Foundation 2027–2028 Embedded Fellowship project linked to SRHIN's published challenge. It is not a Mozilla award, an SRHIN partnership, a real cooperative, or a community pilot.

## Rules that must always be followed

- Use fictional examples only. Never use real mental-health, patient or participant information.
- Do not change DavDeploy repositories, production domains or unrelated Cloudflare services.
- Keep the project public under the Apache-2.0 license. Make changes through pull requests.
- Do not enable paid services or incur charges.
- Keep credentials out of code, documents, logs, browser pages and summaries.
- The server checks permissions. An AI model never decides who is allowed.
- Clearly label what works, what is only a test, and what is proposed for later.
- Do not claim clinical suitability, real community ownership, participant approval or benefits delivered.
- Do not write or submit the applicant's personal Mozilla application answers.
- Do not delete local or external resources without the owner's current approval.

## What the project should provide

A public website and source repository, a bounded demonstration using a real AI model on synthetic text, automated checks, a public video, a clearly labelled future design, and accurate research and security notes.

## How to track completion

Use the [acceptance checklist](CHECKLIST.md). A task is complete only when there is evidence. A deployment must be checked at its public address, including its server behavior, model path, free-plan status and independence from this Mac.

# Demonstration video outline

**Target:** 90–120 seconds. Record the actual production application only after live behavior is verified. Speak plainly and label the community and all records as fictional.

1. **0:00–0:15:** Explain that communities can contribute information while having limited say in later AI uses. Introduce MindCommons as an early technical prototype, not a real cooperative.
2. **0:15–0:35:** Show a synthetic community rule and explain how it became effective in the demo.
3. **0:35–0:55:** Show individual permission and the proposed research purpose; submit the fixed allowed job.
4. **0:55–1:15:** Show the actual backend authorization, model identifier, inference result and provenance. State that the inputs are synthetic.
5. **1:15–1:35:** Submit the prohibited request and show the server rejection. Explain that AI is not called.
6. **1:35–1:50:** Show audit evidence and a hypothetical community benefit commitment.
7. **1:50–2:00:** Show source and next co-design steps. Do not imply SRHIN endorsement or community participation.

If a real model call fails, do not edit in a simulated success. Record the limitation and show the truthful error state.

# Reviewer guide

**Status:** the backend demo is implemented and verified locally but is not publicly hosted. The public future-product visualization is available at <https://bepoadewale.github.io/mindcommons/>. Its expandable screen details are static concepts; it has no API or AI execution. To explore the functional local backend, run `npm ci` then `npm run dev`, and open `http://127.0.0.1:8788`. Its AI step returns an explicitly labelled deterministic test result, not model inference. Open `/vision/` on the local origin for the same future-product visualization.

The verified local journey is: read the fictional community's active rules; inspect the separate fictional individual permission; submit a fixed, allowed synthetic research evaluation and observe the mock label; submit a prohibited commercial-use request and confirm the server denies it before inference; withdraw the synthetic permission and confirm another denial; approve the sample policy proposal and observe version 2; add hypothetical benefit evidence; inspect audit events; reset the visitor's isolated session. The production AI call remains unverified.

The page identifies implemented and proposed capabilities. A mocked test result is not live inference evidence. Any pilot plans are not partnership or participant feedback.

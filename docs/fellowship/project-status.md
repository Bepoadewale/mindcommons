# Project status

**Status on 2026-11-17:** the local technical prototype and public vision page are merged to the public repository's protected `main` through PR #13. The demo has a synthetic community, proposal approval, separately stored permission withdrawal, deterministic server-side authorization, fixed research job, hypothetical benefit evidence, provenance, audit events, session reset and isolation. Local tests use a named mock instead of hosted inference. The `/vision/` future-product wireframe has eight proposed screens and is clearly labeled.

Local and CI evidence currently verified: 17 unit tests; 4 fixture-backed browser tests; 3 static vision browser tests; local Worker + D1 API integration; built-UI-to-Worker full-stack browser journey; axe WCAG 2.1 A/AA checks on the demo, local `/vision/`, and public vision page; strict type checks, lint, production build, documentation validation and CI secret-scan. PR #8 CI passed all four required jobs; deployment run `43986205720` succeeded. Live Chromium confirmed all eight public proposed screen previews, mobile fit at 390 px, no API requests or failed assets, and zero axe WCAG 2.1 A/AA violations. The full-stack path confirms the mock stays explicitly labeled. A live AI call, public backend deployment, Android device installation, video, human feedback, and pilot have not been verified. The Worker Static Assets migration is in an unmerged PR branch; the deployed public vision page remains the static-only fallback.

The selected technical direction is a React/TypeScript frontend with Cloudflare Workers Static Assets, a narrow TypeScript API Worker, D1 and bounded Workers AI inference. A local, unmerged branch is migrating the API to this model; current `main` has not changed. The Keychain token identifies the account and permits read access, but its account-wide scope includes 297 permission groups and unrelated DNS, zone, route and email writes. It will not be used for deployment. The subscription list is empty and billable-usage info says `covered: false`; the account's Workers Free status still needs explicit billing-view confirmation. No Cloudflare resource has been changed or created.

The prototype is intended for synthetic Nigerian community mental-health research scenarios. It is not a clinical product, not a data cooperative, not an SRHIN partnership, and not evidence of community consent or ownership. Cloud deployment is blocked pending confirmation of the account plan and suitable write permissions for isolated resources. No Cloudflare mutation has been made. RFP notes and research links are in this repository; submitted fellowship answers remain the applicant's own work and voice.

The future-product visualization is published at <https://bepoadewale.github.io/mindcommons/>. GitHub Pages is configured only for this repository's Actions workflow; the built artifact is static, makes no API requests, and has no live AI behavior.

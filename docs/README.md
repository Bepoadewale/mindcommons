## Key words in plain English

- **AI model:** software that finds patterns or produces results from examples.
- **Community rule:** a rule agreed through a community process about which uses are allowed.
- **Individual permission:** one person's choice about how their own contribution may be used.
- **Authorization check:** the software's check that a request follows the current rules and permissions.
- **Inference:** when an AI model processes an input to produce a result.
- **Synthetic data:** made-up examples created for testing, not records about real people.
- **Benefit commitment:** something a research team agrees to provide, such as an accessible summary.
- **Decision receipt:** a downloadable record explaining why a request was allowed or denied.
- **JSON:** a common text format for data that software can read.
- **Mock:** a substitute used in tests; it does not call a real AI model.
- **Co-design:** making choices together with the people affected, with a real chance to change the design.

# Project status

**Status on 2026-11-17:** the local technical prototype and public vision page are merged to the public repository's protected `main` through PR #12. The demo has a synthetic community, proposal approval, separately stored permission withdrawal, deterministic server-side authorization, fixed research job, hypothetical benefit evidence, provenance, audit events, session reset and isolation. Live Chromium confirmed all eight public proposed screen previews, mobile fit at 390 px, no API requests or failed assets, and zero axe WCAG 2.1 A/AA violations. The full-stack path confirms the mock stays explicitly labeled. A live AI call, public backend deployment, Android device installation, video, human feedback, and pilot have not been verified.

The selected technical direction is a React/TypeScript frontend with Cloudflare Pages Functions, D1 and a bounded Workers AI inference call. The existing general Keychain token identifies the intended Cloudflare account and allows read-only Pages/D1 listing, but subscription/billing lookup is denied and the account's plan cannot be confirmed. The separate provisioner token still cannot enumerate an account. No Cloudflare resources have been changed or created.

The prototype is intended for synthetic Nigerian community mental-health research scenarios. It is not a clinical product, not a data cooperative, not an SRHIN partnership, and not evidence of community consent or ownership. Cloud deployment is blocked pending confirmation of the account plan and suitable write permissions for isolated resources. No Cloudflare mutation has been made. RFP notes and research links are in this repository; submitted fellowship answers remain the applicant's own work and voice.

The future-product visualization is published at <https://bepoadewale.github.io/mindcommons/>. GitHub Pages is configured only for this repository's Actions workflow; the built artifact is static, makes no API requests, and has no live AI behavior. Its eight proposed screen concepts are available through accessible client-side disclosure previews. The Cloudflare backend demo and Workers AI call remain unavailable.

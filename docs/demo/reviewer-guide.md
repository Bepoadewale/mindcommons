# Reviewer guide

**Status:** the hosted application is not yet available. This guide describes the planned demonstration; do not treat it as working until the deployment checklist is complete.

The intended journey is: read the fictional community's active rules; inspect the separate fictional individual permission; submit a fixed, allowed synthetic research evaluation; inspect the backend decision, actual model execution and provenance; submit a prohibited commercial-use request and confirm it is denied before inference; inspect the audit event and hypothetical benefit commitment; reset the visitor's isolated demo session.

The page must identify each capability as implemented, prototype, or proposed. A mocked test result is not live inference evidence. Any pilot plans are not partnership or participant feedback.

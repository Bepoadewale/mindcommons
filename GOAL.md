# MindCommons goal

## Mission

Build and verify an open-source, public-interest technical prototype that demonstrates enforceable, community-informed governance over synthetic AI research inputs and results. Prepare accurate technical evidence for a possible Mozilla Foundation 2027–2028 Embedded Fellowship proposal associated with SRHIN's published challenge. MindCommons is not an awarded project, confirmed host partnership, community cooperative, or real pilot.

## Immutable constraints

- Synthetic data only; no real mental-health or patient data.
- Never modify DavDeploy repositories, production domain, or Cloudflare resources.
- Public open-source repository; Apache-2.0; all changes to `main` through pull requests.
- Use only verified free-tier services. Do not upgrade, enable paid services, or incur charges.
- Keep credentials out of the repository, logs, docs, browser, and summaries.
- Enforce authorization server-side and fail closed; an LLM never decides authorization.
- Distinguish live behavior, deterministic test doubles, planned capabilities, and future research.
- Do not claim clinical suitability, human-subject validation, real community ownership, or benefits delivered.
- Do not submit a Mozilla application or write personal application answers for the applicant.
- No deletion of local or external resources without current explicit approval.

## Target outputs

Public reviewer website, standalone GitHub repository, real bounded AI demonstration, automated verification, public technical video, public interactive future vision or Figma design, architecture/security/governance research, and accurate Mozilla RFP evidence.
